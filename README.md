# 千壁浮光 · 原位构视版

以敦煌莫高窟第 61 窟《五台山图》为主题的本地交互网页，现已增加“原位构视”三维空间。

## 打开

直接双击 `index.html`，或双击 `打开网页.command`。点击“进入原位构视”。保持整个文件夹完整即可离线展示，无需为访客安装插件。外部资料来源链接需要联网。

本机预览地址为 http://127.0.0.1:4173/#gallery ，仅在本地预览服务运行时可用。

## 原位构视

- 真实 WebGL 三维场景：按公开洞窟照片与西壁整图组织主室观看关系。
- 西壁保持完整上下层图像：上部《五台山图》与下层壁画一起呈现。
- “洞口”“主室”“西壁”“近观”“剖视”五个观看位置；剖视暂时隐藏顶部及部分墙体，呈现主室、西壁与中央台基的关系。
- 鼠标或单指拖动转向；画面获得焦点后，滚轮或双指拉近拉远。
- 键盘方向键转向，加减号调整距离，Home 归位，Escape 退出。
- “缓缓环视”开启或暂停自动观看；默认静止，系统减少动态效果时关闭过渡动画。
- 点击西壁上层进入原有的原图细节讲解；下层展示待考证说明；“细读画卷”回到完整平面图。
- 3D 场景中的色彩滑块在“现状影像、明暗调整、色彩增强、复色设想”四个阶段间连续过渡，也可播放或暂停整个过程。
- 离开洞窟可见区域或切走浏览器标签后停止渲染；不支持 WebGL 2 的浏览器仍可使用图文探索。
- 3D 资源仅在进入时加载，西壁图像与处理阶段已本地打包，直接打开文件也可使用。

本版实现的是基于公开资料的原位构视示意。现有素材没有整窟激光扫描、逐墙高清壁画图或完整测绘数据，空间不是第 61 窟的精确三维复原；场景只用于理解观看位置、墙面关系与壁画尺度。侧墙保持未考证留白，没有把局部图像移植为真实侧墙壁画。

## 原有功能

- 作品开场、文化背景和来源说明。
- 壁画拖动、1–4 倍缩放、返回全图及展开浏览。
- 六个按画面从左到右排列的观察点、已看计数和六站导览。目录位于画面上方并随滚动保留，支持上一处／下一处、全图定位和一键进入复色。
- 两个局部的原图与数字调色实验滑块对比。
- 电脑和手机响应式排版、键盘交互。

## 内容来源

史实依据数字敦煌第 061 窟介绍，2026 年 10 月 12 日核验；六个热点为原图观察，不对具体人物或寺院作未经核验的命名。导览是一条设计的观看路线。

色彩步骤使用本地 Canvas 对现状图像做亮度、对比度、饱和度与轻微色温调整。后面三档是数字视觉实验，最后一档是艺术化复色设想，不代表历史原色复原，也不替代颜料检测或保护修复研究。图像来自既有参考素材，保留来源水印。本版供本地研讨演示；对外发布前，按来源方规则落实使用条件。

- 外景：https://www.dha.ac.cn/skxl/mgk.htm

## 开发与文件

页面浏览无需构建或安装依赖。`index.html` 为内容，`styles.css` 为视觉与适配，`app.js` 为原有交互，`gallery-loader.js` 按需加载本地 `gallery.bundle.js`，`assets` 为本地图片。

3D 源码在 `src/gallery.js`，使用固定版本 Three.js 0.180.0（MIT，见 `THREE-LICENSE.txt`）。需要修改三维场景时，安装项目依赖后运行 `npm run build` 重新生成本地包。打包工具为 esbuild 0.25.11。`package-lock.json` 固定依赖版本。

`qa/3d-results.json` 记录 3D 验证，`qa/results.json` 记录原有交互回归验证；截图在 `qa` 内。本机自动验证使用独立 Chrome 测试环境，手机手势为浏览器模拟，尚未覆盖所有实体手机。
